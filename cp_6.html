5  框架开发实践

5.1 框架开发

5.1.1 为何需要智能体框架

我们先不谈任何具体框架。我们问一个更基础的问题：一个大模型 + API，够不够？

LLM 本质是什么？一个条件概率生成器，输入上下文（context），输出下一个 token的概率分布。它不会主动执行任务，也不会管理长期状态，也不会调用工具，不会协调多个角色，更不会维护目标。它只是一个 推理引擎（inference engine）。

现实任务的结构为：

目标 (Goal)
    ↓
拆解 (Decomposition)
    ↓
行动 (Action)
    ↓
反馈 (Feedback)
    ↓
迭代 (Iteration)

你有目标，然后你需要拆解目标，划分到具体的行动，然后行动有反馈，根据反馈调整自己。

例如写代码、做商业分析、自动化运维、研究问题、规划路线。

这些都不是“一次生成”能完成的。

它们需要多步推理 + 工具调用 + 状态更新 + 记忆 + 反思。

LLM 是“单步预测器”，现实任务是“多步闭环系统”，这中间存在结构缺失。这就是为什么我们需要“Agent 框架”。

Agent 框架解决的本质问题：

从结构上讲，它补充了 5 个核心能力：

能力 解决什么问题
任务循环 (Loop) 让模型可以多步推理
工具调用 (Tooling) 连接外部世界
记忆 (Memory) 维持长期状态
规划 (Planning) 目标分解
多角色协作 (Multi-agent) 复杂系统拆解

5.1.2 智能体框架的核心分类

1 第一类：Prompt 编排型

  • LangChain

  • LlamaIndex

本质是把 Prompt、工具、链式调用进行封装。核心思想：

输入 → 模板 → LLM → 输出

优点是上手快、文档多、生态成熟，缺点是控制流复杂、抽象层叠加、调试困难。
2 循环驱动型（ReAct / Plan-Act）

  • AutoGen

  • AgentScope

  • CAMEL

本质是显式构建：

思考 → 行动 → 观察 → 反思

核心是让模型参与“决策循环”。

优点是更贴近智能结构、多 Agent 协作强、可构建复杂系统。

缺点是成本高、Token 消耗大、控制稳定性难。

3 图结构 / 工作流型

  • LangGraph

本质用图结构（Graph）定义状态节点、转移边、条件分支。它本质是把 Agent 显式建模成状态机。

优点是可控性强、可复现、可调试。

缺点是构建复杂需要设计能力。

我们暂时先讲循环驱动型框架，还有LangGraph。

5.2 框架一：AutoGen

AutoGen做的是什么？LLM 是单步预测器，AutoGen 要做的是：

目标
 ↓
多个角色
 ↓
对话循环
 ↓
直到达成任务

它补的是任务循环、多 Agent 角色、自动终止机制。

5.2.1 AutoGen 的最小结构

把AutoGen的结构元素抽象成 3 个对象：

  1. Agent（角色）
  2. Message（消息）
  3. Loop（对话循环）

你可以理解为：角色 + 消息机制 + 自动往返

5.2.2 极简 AutoGen 案例

我们做一个最小可运行案例：让一个“提问者”问问题，让一个“回答者”回答，然后自动停止。

AutoGen 确实经历了一次重大的从零重写（Complete Rewrite），让Agent 成为“任务执行单元”。AutoGen v0.4 版本于 2025年1月14日至17日 期间正式发布。

我们用最新的版本。

import asyncio
from autogen_agentchat.agents import AssistantAgent
from autogen_ext.models.ollama import OllamaChatCompletionClient


async def main():
    # 连接 Ollama
    model = OllamaChatCompletionClient(
        model="llama3.1",  # 你本地模型名
    )

    # 创建 Assistant
    assistant = AssistantAgent(
        name="assistant",
        model_client=model,
        system_message="You are a concise assistant."
    )

    # 运行对话
    result = await assistant.run(
        task="解释一下什么为什么天是蓝色的。"
    )

    print(result.messages[-1].content)

    await model.close()


asyncio.run(main())

输出：

天是蓝色的主要原因是由于地球大气中空气分子和太阳光线的相互作用。这一过程被称为散射现象。

当阳光穿过地球的大气层时，白光会被分解成各种颜色的光谱。其中，蓝色光有较小的波长，从而被更加有效地散射出，大气中空气分子的尺寸相对较小。当这些散射出的蓝色光线到达我们的眼睛时，我们就看到了天上的蓝色。

此外，地球大气层中的水蒸汽和其他气体也会影响阳光的颜色，使得我们看到的天色更加接近蓝色。

让我们来拆解代码，import asyncio ，为什么必须 async？因为模型调用是 IO 操作，而且网络请求是异步的，支持并发。

model = OllamaChatCompletionClient(
    model="llama3.1",
)

这是模型连接层，它负责封装请求，调用HTTP，返回结果解析。

不同模型平台 = 不同的 ModelClient，OllamaChatCompletionClient对应ollama。

OpenAI 官方接口：from autogen_ext.models.openai import OpenAIChatCompletionClient

其他的具体看：https://microsoft.github.io/autogen/stable/user-guide/agentchat-user-guide/tutorial/models.html#openai

遵守相同协议的应该可以共用。

assistant = AssistantAgent(
    name="assistant",
    model_client=model,
    system_message="You are a concise assistant."
)

创建 AssistantAgent，这 3 个东西足够构成一个“认知单元”。你要看到一个关键点，system_message = 行为约束层。它定义了语气、角色、输出风格。

result = await assistant.run(
    task="Explain what a list comprehension is in Python in one sentence."
)

这是关键。 run() 做了什么？内部等价于：

1. 构建消息列表
   - system_message
   - user task

2. 调用 model_client

3. 返回 structured result

它做了很多抽象，这意味着未来它可以：多步推理、工具调用、内部循环、记忆扩展。

result.messages[-1].content

AutoGen 不返回“字符串”，它返回：

ChatResult
    messages: List[Message]

所有 Agent 执行结果都保留完整消息历史。这是为了支持多轮、审计、追踪、继续对话。

流式输出的例子：

import asyncio
from autogen_agentchat.agents import AssistantAgent
from autogen_ext.models.ollama import OllamaChatCompletionClient


async def main():
    model = OllamaChatCompletionClient(
        model="llama3.1",
    )

    assistant = AssistantAgent(
        name="assistant",
        model_client=model,
        system_message="You are a concise assistant."
    )

    # 使用 run_stream()
    async for chunk in assistant.run_stream(
        task="解释一下天为什么是蓝色的？"
    ):
        # chunk 可能是多种事件类型
        if hasattr(chunk, "content") and chunk.content:
            print(chunk.content, end="", flush=True)

    await model.close()


asyncio.run(main())

5.2.3 稍复杂的例子

import asyncio
from autogen_agentchat.agents import AssistantAgent
from autogen_agentchat.teams import RoundRobinGroupChat
from autogen_ext.models.ollama import OllamaChatCompletionClient


async def main():
    model = OllamaChatCompletionClient(
        model="llama3.1",
    )

    coder = AssistantAgent(
        name="Coder",
        model_client=model,
        system_message="You are a Python coder. Respond only with code."
    )

    reviewer = AssistantAgent(
        name="Reviewer",
        model_client=model,
        system_message=(
            "You are a strict reviewer. "
            "If correct, say APPROVED. Otherwise explain issues."
        )
    )

    team = RoundRobinGroupChat(
        participants=[coder, reviewer],
        max_turns=6,
    )

    async for event in team.run_stream(
        task="Write Python code to compute the sum of squares from 1 to 100."
    ):
        # 只打印真正的文本内容
        if hasattr(event, "content") and event.content:
            print(f"\n[{event.source}] ", end="", flush=True)
            print(event.content, end="", flush=True)

    await model.close()


asyncio.run(main())

输出:

重点看：

team = RoundRobinGroupChat(
    participants=[coder, reviewer],
    max_turns=6,
)

这是核心结构。RoundRobinGroupChat 意味着：Coder → Reviewer → Coder → Reviewer ...直到达到 max_turns或者内部终止。它是一个有限状态循环控制器。

async for event in team.run_stream(...)

是流式执行机，这一步极其重要。这是一个异步事件流系统。

习的时候可以注意一点，使用autogen最新版本的包可能出现一些bug，有些教程的代码使用的是老的比较稳定的包，但是上面用的是比较新的，agent发展有点快，代码可能经常变。

5.3 框架二：AgentScope

一个 Agentic App 逃不掉这条因果链：输入（需求/对话） → 推理（LLM） → 决策（下一步做什么） → 行动（调用工具/发消息/写入状态） → 反馈（工具返回/他人回复） → 循环直到完成

https://github.com/agentscope-ai/agentscope

人家更新代码频率挺快的，有些教程代码报错的话问下ai，或者看看官网。

5.3.1 1 怎么安装？

uv pip install agentscope

AgentScope 本身不提供模型，它只是框架。

你必须选择一个模型来源。

验证安装是否成功

import agentscope
print("OK")

5.3.2 2 最小可运行代码是什么？

from agentscope.agent import ReActAgent, UserAgent
from agentscope.model import OllamaChatModel
from agentscope.formatter import OllamaChatFormatter
from agentscope.memory import InMemoryMemory
from agentscope.tool import Toolkit, execute_python_code, execute_shell_command
import os, asyncio


async def main():
    toolkit = Toolkit()
    toolkit.register_tool_function(execute_python_code)
    toolkit.register_tool_function(execute_shell_command)

    agent = ReActAgent(
        name="Friday",
        sys_prompt="You're a helpful assistant named Friday.",
        model=OllamaChatModel(
            model_name="llama3.1", # qwen2.5:1.5b也可以
        ),
        memory=InMemoryMemory(),
        formatter=OllamaChatFormatter(),
        toolkit=toolkit,
    )

    user = UserAgent(name="user")

    msg = None
    while True:
        msg = await agent(msg)
        msg = await user(msg)
        if msg.get_text_content() == "exit":
            break

asyncio.run(main())
